I'm a Senior Software Engineer specializing in **Go backend services** for commerce and financial systems. I build pricing, risk, and transaction-limit services with an emphasis on clear boundaries and maintainable code.

- Building an **offer-pricing service** in Go on AWS
- Helping define **Go development practices** for a backend team
- Built **risk-calculation and transaction-limit services** for financial systems
- Exploring **gRPC, messaging, and distributed systems** through personal Go studies
